# Ahorro y fondo de emergencia

Ahorrar no es solo guardar lo que sobra; normalmente funciona mejor cuando apartas una cantidad fija apenas recibes ingresos. Un presupuesto sencillo puede dividir el dinero entre gastos esenciales, metas de ahorro y gastos variables.

El fondo de emergencia sirve para cubrir imprevistos como una reparación, una urgencia médica o una baja temporal de ingresos. Una referencia común es construir un colchón de entre tres y seis meses de gastos esenciales, empezando por una meta pequeña y alcanzable.

Para ahorrar más, conviene identificar gastos recurrentes que no aportan tanto valor, automatizar transferencias a una cuenta separada y evitar mezclar el ahorro de corto plazo con el dinero de uso diario. Medir el avance cada semana o cada mes ayuda a sostener el hábito.

Si tus ingresos cambian mucho, puede servir calcular un promedio mensual y definir un porcentaje mínimo de ahorro para cada pago que recibas. La constancia suele ser más importante que intentar ahorrar una cantidad perfecta desde el primer mes.
