# 7. Alcance del MVP

## Dentro de alcance

- aplicación web responsive;
- autenticación segura con email/contraseña y OAuth;
- perfil configurable;
- registro multimodal mediante:
  - formulario estructurado;
  - texto libre en lenguaje natural;
  - notas de voz;
  - fotografía de recibos/facturas;
- dashboard con saldo neto, ingresos/egresos, gráficas y tendencias;
- base de conocimiento curada de 20 temas prioritarios;
- chatbot con acceso al historial financiero y al corpus RAG;
- registro de transacciones desde chat;
- almacenamiento de documentos en la nube;
- exportación CSV;
- exportación PDF;
- lanzamiento beta y pruebas QA.

## Fuera de alcance

- integración directa con APIs bancarias o del SAT;
- aplicación móvil nativa;
- soporte multi-país;
- foros, pláticas y eventos financieros;
- sincronización automática bancaria.
