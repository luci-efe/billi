# 14. Restricciones y supuestos

## Restricciones

- presupuesto limitado;
- producto en español y orientado a México;
- sin integraciones bancarias o SAT en esta fase;
- dependencia de proveedores externos de IA y storage.

## Supuestos

- los usuarios están dispuestos a registrar movimientos manualmente o de forma asistida;
- el corpus del RAG puede curarse manualmente durante el MVP;
- el equipo mantendrá la entrega dentro de una ventana de 10 semanas;
- los costos de IA se mantendrán dentro de rango razonable para el MVP.
