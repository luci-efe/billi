# 11. Definición de beta ready

Un release se considera listo para beta cuando:

- la funcionalidad mínima comprometida del MVP está implementada;
- los flujos principales funcionan como se espera en pruebas internas;
- el equipo valida internamente el sitio de punta a punta;
- los errores abiertos no bloquean registro, dashboard, chatbot, documentos, exportación ni gestión básica de plan.
