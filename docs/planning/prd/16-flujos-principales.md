# 16. Flujos principales

## Flujo 1. Registro de egreso por foto

- el usuario sube o toma una foto;
- el sistema procesa la imagen;
- se muestra una propuesta editable;
- el usuario confirma o corrige;
- el documento y la transacción quedan vinculados.

## Flujo 2. Consulta al chatbot

- el usuario pregunta por su historial o por un concepto financiero;
- el sistema clasifica la intención;
- consulta datos personales o RAG según corresponda;
- responde con trazabilidad y límites claros.

## Flujo 3. Registro de ingreso por voz o chat

- el usuario escribe o dicta un ingreso;
- el sistema interpreta entidades;
- se muestra confirmación editable;
- la transacción queda guardada tras aprobación.

**Nota de alcance:** la captura por voz dentro del chat queda como capacidad deseable si el tiempo lo permite. La captura por voz del producto sigue siendo parte del MVP, pero la variante específicamente embebida en chat no bloquea beta.
