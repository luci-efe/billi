# 3. Problema y oportunidad

## Problemas que resuelve

- gastos hormiga no registrados;
- poca claridad sobre ingresos, egresos y patrones de gasto;
- dificultad para entender SAT, ISR, IVA, AFORE, CETES y otras nociones financieras mexicanas;
- alta fricción en herramientas manuales como hojas de cálculo o notas.

## Oportunidad

Billi puede diferenciarse de competidores como Finerio o BBVA Wallet combinando educación financiera contextualizada, captura multimodal y un asistente capaz de responder tanto sobre el historial personal como sobre conocimiento financiero curado.
