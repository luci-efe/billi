# 12. Guardrails del asistente

- el asistente no es fuente de verdad para cálculos financieros;
- las respuestas sobre historial deben salir de lógica determinista sobre datos del usuario;
- las respuestas educativas deben usar recuperación sobre contenido curado;
- el asistente debe admitir incertidumbre y activar fallback cuando no tenga soporte suficiente;
- no debe presentarse como asesor financiero regulado.
