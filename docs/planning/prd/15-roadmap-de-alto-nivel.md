# 15. Roadmap de alto nivel

## Fase 1. Fundación

- esquema de base de datos;
- autenticación;
- formularios de ingreso/egreso.

## Fase 2. Core visual

- dashboard;
- almacenamiento de recibos;
- perfil;
- exportación CSV.

## Fase 3. Inteligencia RAG

- estructura del RAG;
- curación de 20 temas;
- vectorización e indexación.

## Fase 4. Chatbot integrado

- chat conectado al historial;
- chat conectado al RAG;
- captura por texto natural y voz.

## Fase 5. Refinamiento

- OCR de recibos;
- exportación PDF premium;
- QA;
- lanzamiento beta.
