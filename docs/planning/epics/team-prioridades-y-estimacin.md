# Team, prioridades y estimación

- `team`: uno solo para todo el backlog
- `sub-issues`: uso mínimo; preferir dependencias entre historias

## Escala de prioridad

- `urgent`: bloquea la ruta crítica o desbloquea muchas historias
- `high`: esencial para MVP
- `medium`: importante pero secuenciable después
- `low`: deseable o claramente opcional

## Método de estimación

Cada historia debe guardar:

- `estimate_o`
- `estimate_r`
- `estimate_p`
- `estimate_score = (O + 4R + P) / 6`
- `estimate_tshirt`

Conversión a T-shirt:

- `XS`: <= 1.5
- `S`: > 1.5 y <= 2.5
- `M`: > 2.5 y <= 4
- `L`: > 4 y <= 6.5
- `XL`: > 6.5
