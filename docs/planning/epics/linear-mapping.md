# Linear Mapping

## Modelo recomendado

- `Initiative`: `Billi MVP`
- `Team`: uno solo
- `Projects`:
  - `PRJ-01 Fundación y Core`
  - `PRJ-02 RAG, Chatbot y MVP`
- `Milestones`: `MS-01` a `MS-05`
- `Issues`: `ST-*`
- `Sub-issues`: solo para descomposición de historias grandes

## Reglas de dependencia

- usar `project dependencies` entre épicas;
- usar dependencias entre historias antes que sub-issues;
- usar `milestones` para las 5 fases del roadmap;
- usar `blocked_by` y `blocking` en stories;
- no usar sub-issues como checklist genérico.
