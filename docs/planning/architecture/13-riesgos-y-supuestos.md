# 13. Riesgos y supuestos

## Riesgos

- más trabajo de backend explícito al salir de Convex;
- necesidad de definir estrategia simple de updates sin realtime;
- costo y latencia de IA/OCR/STT;
- complejidad de billing si se implementa demasiado pronto.

## Supuestos

- el edge runtime de Cloudflare será suficiente para el BFF;
- Turso cubrirá el MVP sin necesidad de sync avanzada;
- el vector search nativo será suficiente para el corpus inicial.
