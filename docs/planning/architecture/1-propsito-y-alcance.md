# 1. Propósito y alcance

Este documento define la arquitectura objetivo de Billi tomando como baseline los BRD/PRD originales y actualizando la capa técnica para usar `LibSQL/Turso` en lugar de `Convex`.

El alcance cubre:

- frontend web;
- API/BFF;
- autenticación;
- base de datos relacional;
- almacenamiento de archivos;
- RAG y asistente;
- exportaciones;
- jobs largos;
- observabilidad y seguridad.
