# 6. Pantallas clave

## 6.1 Landing / onboarding

- propuesta de valor concreta;
- explicación breve del problema que resuelve;
- aclaración de uso de datos;
- CTA principal único.

## 6.2 Auth

- login;
- registro;
- OAuth;
- recuperación de acceso si se implementa.

## 6.3 Registrar movimiento

- selección de modalidad;
- captura rápida;
- validación inline;
- revisión editable.

## 6.4 Dashboard

- saldo neto;
- ingresos y egresos del periodo;
- desglose por categoría;
- últimas transacciones;
- comparativa con periodo anterior;
- estados vacíos útiles.

## 6.5 Facturas

- galería/lista;
- búsqueda;
- filtro;
- preview;
- vínculo a transacción.

## 6.6 Chatbot Billi

- preguntas sobre historial;
- preguntas sobre RAG;
- captura por texto natural;
- recepción de voz si se implementa dentro del chat;
- respuesta con fuente o explicación del origen.

## 6.7 Ajustes y plan

- datos de perfil;
- preferencias;
- privacidad;
- plan gratuito/premium;
- límites y beneficios.
