# 8. Diferenciación entre plan gratuito y premium

## Gratuito

- registro ilimitado;
- dashboard básico;
- RAG con límites;
- hasta 10 recibos por mes;
- CSV.

## Premium

- dashboard avanzado/histórico;
- chatbot extendido;
- recibos ilimitados;
- PDF;
- recomendaciones, alertas y metas.

## Implicaciones UX

- los bloqueos premium deben explicarse con valor, no solo con restricción;
- el usuario debe entender qué obtiene al subir de plan;
- los límites del gratuito deben ser visibles antes de chocar contra ellos.
