# 5. Jornadas principales

## 5.1 Alta y configuración inicial

- ver propuesta de valor;
- revisar consentimiento;
- crear cuenta o iniciar sesión;
- configurar nombre, moneda y categorías;
- llegar a dashboard o empty state guiado.

## 5.2 Registro de movimiento

El usuario puede elegir:

- formulario;
- texto libre;
- voz;
- imagen.

Todas las rutas deben converger en una revisión clara antes del guardado cuando exista interpretación automática.

## 5.3 Consulta de estado financiero

- ver balance;
- ver ingresos/egresos;
- revisar categorías;
- comparar tendencia;
- abrir detalle cuando haga falta.

## 5.4 Consulta al asistente

- preguntar por historial;
- preguntar por conceptos financieros mexicanos;
- registrar un movimiento desde la conversación;
- ver trazabilidad y límites.

## 5.5 Exportación y plan

- entender qué exporta cada plan;
- ver si CSV o PDF está disponible;
- comprender por qué una funcionalidad está bloqueada;
- decidir si actualizar plan.
