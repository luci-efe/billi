# 3. Principios de experiencia

- **Registro sin fricción.** Capturar un movimiento debe ser más fácil que abrir una hoja de cálculo.
- **Confirmación sobre automatización.** La IA ayuda, pero no guarda datos ambiguos sin revisión.
- **Claridad premium.** Las capacidades premium deben verse como mejoras comprensibles, no como trampas oscuras.
- **Contexto mexicano visible.** El lenguaje, ejemplos y educación financiera deben sentirse locales.
- **Confianza explícita.** Consentimiento, privacidad y trazabilidad deben ser visibles, no implícitos.
